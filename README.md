<h1 align="left">Hi, I'm Sathmi</h1>

<p align="left">
I build applied AI systems in Python and TypeScript. My recent work covers LLM agents,
retrieval-augmented generation (RAG), and the evaluation methods that show whether
they work, from LLM-as-judge scoring of RAG assistants to load tests of a
full-stack AI tutor.
</p>

<p align="left">
I focus on making model output checkable: numbers that come from deterministic code
instead of the model, citations that are verified before they reach the user, and
results reported with their sample sizes. I am looking for machine learning and
data science internships.
</p>

---

### What I'm working on

- **AstroAI**: a space-physics tutor whose agent calls a deterministic physics engine for every number and verifies paper citations in code, measured with its own evaluation harness and k6 load tests. *TypeScript · Python · FastAPI · PostgreSQL + pgvector · Gemini*
- **Car Manual QA Evaluator**: a research pipeline that generates question–answer sets from vehicle manuals and scores RAG assistants' answers with LLM judges across five metrics. *Python · OpenAI · Gemini · DeepSeek · PyMuPDF*
- **PromptCraft**: a prompt-engineering course platform with 18 lessons, practice questions, and LLM feedback on learners' answers. *React · Express · Firebase · OpenAI*
